# 游戏化人生手册

> **好体验 + 值得 + 再试一次 = 一场不后悔的人生。**
> 24 章方法论 + 100 条可以抄走的机制。全套用纸笔就能实现。

---

## 这是什么

市面上讲「该做什么」的书已经够多了。早睡、运动、拆任务、少刷手机——这些你全知道。你缺的不是清单，是**启动的那一下**。

这本书讲另一件事：**游戏为什么能让人自愿投入几百小时，而你的待办清单不能。以及怎么把这四个让「愿意」成立的条件，搬到你自己的生活里。**

人生是一场体验。这本书讲的是，怎么让它成为一场不后悔的体验。

## 三条支柱

| 支柱 | 意思 | 负责什么 | 缺了会怎样 |
|---|---|---|---|
| **好体验** | 过程是好的 | 让你愿意开始 | 又一份清单，看完就放着 |
| **值得** | 做完觉得值 | 让你做的有意义 | 又一个游戏，玩完什么都没留下 |
| **再试一次** | 断了还能接着来 | 不被一次中断打败 | 又一套靠意志力硬撑的系统 |

三个词都是主动的，没有一个在说「你要忍」。

### 为什么是「值得」不是「有用」

「有用」是别人的尺子——对社会有用、对工作有用、对赚钱有用。
「值得」是自己的尺子——回头想起来，这段日子没白过。

而且「有用」对每个人的定义都不一样。同一件事，对 A 很有用，对 B 可能完全没用。一本写着「有用」的书，其实在替读者下判断。

「值得」不用替任何人判断。它只问一句：**你自己回头看的时候，觉得值吗。**

### 为什么是「再试一次」不是「撑得住」

「撑得住」在说：**你要忍。**
「再试一次」在说：**你可以选。**

中断一定发生，这是事实。关键是把中断之后的那一步变成一个动作，而不是一次品质考验。

### 无用之用，方为大用

有些事现在看不出用处，但它构成了「值得」本身。

刷剧、发呆、散步、跟人闲扯到半夜、研究一个完全不能变现的东西——按「性价比」的逻辑全是浪费。但一场不后悔的人生，靠的正是这些时刻。

所以这本书**不劝人删掉「没用的事」**。它甚至建议你每周留一件。

这不是安慰话，是一条可检验的判断：一件事只有用、完全不好玩 → 你做不长；一件事看起来没用、但你愿意反复做 → 它在你人生里一定有位置，只是那个位置还没显形。

## 怎么读

**不用全做。** 这是一份可抄的机制库，不是任务清单。挑走一两条就算数。

**按场景查，不用按顺序读。** 你卡在哪，就去那个场景找：

| 我现在的状态 | 去哪找 |
|---|---|
| 一开始就动不了 | 场景 A（12 条） |
| 任务太大拆不动 | 场景 B（10 条） |
| 做了但看不到结果 | 场景 C（10 条） |
| 中途崩了 | 场景 D（12 条） |
| 一直拖着不做 | 场景 E（10 条） |
| 越做越空，没意义 | 场景 F（9 条） |
| 计划被打乱 | 场景 G（9 条） |
| 重复的事做不下去 | 场景 H（9 条） |
| 系统本身变成负担 | 场景 I（9 条） |
| 想有人陪 | 场景 J（10 条） |

**每条都有「最小版」。** 不用下任何 App，用备忘录、纸笔、微信收藏、闹钟都能做。只想拿方法不想用工具的话，读最小版那一栏就够了。

**每条都有验证等级。** A = 我自己连续跑过 30 天以上、有记录可查；B = 跑过但不足 30 天；C = 用过但只有印象；待验证 = 还没试。**标 A 的才能当证据用。**

## 这不是一本产品说明书

里面每个机制，你都能用纸和笔搭出来。

我确实把自己那套做成了一个 App，但那是我自己的事——书里讲的东西，删掉那个 App 照样成立。

判断标准很简单：**把产品名全部删掉，这本书还成立吗？** 成立，它是方法论；不成立，它是说明书。

**书是设计图，产品是已经盖好的那间屋子。** 图纸看得懂，但懒得施工的时候，那间屋子才是一个合理选项——不是必需。

## 一条必须分清的界线

**好体验 ≠ 上瘾。** 这两件事共用同一个东西（多巴胺），方向完全相反。

判据只有一条：**停下来之后，你还觉得值不值。**

- 上瘾：停不下来，停下来就空虚，玩完觉得自己废了
- 好体验：想再来一次，停下来觉得值，玩完觉得自己活过来了

另一点也要说清：**真正的好体验常常包含困难。** 打一个很难的 Boss、跑一场跑不动的步，过程中不舒服，但体验是好的。**舒服是「不用付出」，好体验是「付出得值」。**

第 9 章整章讲的就是这条线——为什么加积分、加排行榜的最后都失败了。

## 我为什么写这个

我不是研究者，我是个注意力很难集中、计划永远在明天、对着一堆待办发呆的人。

这套东西最初只为我一个人做。它跑了 ⟪填：天数⟫ 天，中间断过 ⟪填：次数⟫ 次。书里的每个机制，都是先在我自己身上试出来，才写下来的——不是我读到什么理论然后转述给你。

所以我能保证的只有一件事：**这些是我自己的账本。** 你可以拿去做对照，但不能当成对你有效的证据。

## 理论出处

书里用到的几个骨架不是我自己编的，该说明的地方会在正文里说明：

- **自我决定理论**（Deci & Ryan, 1985）：人的内在动机依赖自主、胜任、归属三个需求
- **心流**（Csikszentmihalyi）：挑战与能力的匹配区间
- **过度理由效应**（Deci, Koestner & Ryan, 1999 元分析）：外在奖励可能挤出内在动机

这三样是学术界的东西，我只是把它们翻译成了能用的操作。凡是理论部分我标明出处，凡是我自己的观察我标明「这是我自己的账本」。

## 写法说明

每条机制六栏，各算各的，不互相折算：

```
- 成本：要花什么（钱 / 时间 / 毅力）
- 说人话：一句日常话的结论
- 做法：具体到能照做
- 最小版：不用 App 怎么实现
- 验证等级：A / B / C / 待验证
- 跑下来：我自己的记录
```
